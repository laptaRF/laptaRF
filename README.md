# Лапта — народная игра России

Одностраничный сайт о русской лапте: история, правила, фотогалерея, видео
и проверочный тест из пяти вопросов. Без сборщиков, без внешних сервисов:
ни Google Fonts, ни счётчиков, ни CDN — весь сайт работает из папки,
в том числе по двойному щелчку по `index.html` и без интернета.

![Как выглядит сайт](images/preview.jpg)

## Что в репозитории

| Файл | Назначение |
| --- | --- |
| `index.html` | страница целиком: разметка и ссылки на остальные файлы |
| `style.css` | все стили; шрифт `Russo One` вшит внутрь, поэтому не зависит от сети |
| `script.js` | тест из пяти вопросов и плавное появление блоков |
| `images/` | фотографии в `webp`, превью для соцсетей, иконки |
| `404.html` | страница для несуществующих адресов |
| `robots.txt` | указания для поисковых роботов |
| `.nojekyll` | чтобы GitHub Pages не обрабатывал файлы через Jekyll |
| `LICENSE` | лицензия MIT на код сайта |
| `ATTRIBUTION.md` | авторы и лицензии изображений |
| `.gitignore` | служебный мусор систем и редакторов |

## Как посмотреть локально

Двойной щелчок по `index.html` — или, если нужен настоящий сервер:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

## Как выложить на GitHub Pages

1. Создайте публичный репозиторий, например `lapta`.
2. **Add file → Upload files** и перетащите **содержимое** папки так, чтобы
   `index.html` оказался в корне репозитория, а не во вложенной папке.
3. **Commit changes**.
4. **Settings → Pages → Source: Deploy from a branch → main → / (root) → Save**.
5. Через минуту сайт откроется по адресу `https://ЛОГИН.github.io/lapta/`.

В описании репозитория стоит указать пару слов о проекте и повесить тему
`github-pages` — так репозиторий выглядит как готовый к выпуску, а не как черновик.

## Что доделать вручную

- В `index.html` у тегов `og:image` и `twitter:image` относительный путь
  `images/preview.jpg`. После публикации замените его на полный адрес вида
  `https://ЛОГИН.github.io/lapta/images/preview.jpg` — иначе превью не покажется в соцсетях.
- `sitemap.xml` не добавлен: нужен полный адрес сайта, а он появится только после публикации.
  Тогда же его стоит упомянуть строкой `Sitemap:` в `robots.txt`.
- В `LICENSE` вместо строки `Автор проекта «Лапта»` впишите своё имя.
- Видео открывается на RUTUBE в новой вкладке — для просмотра нужен интернет.
- Фон первого экрана: источник картинки не подтверждён, подробности в `ATTRIBUTION.md`.

## Проверено

- 1440, 390 и 320 px: боковой прокрутки нет, битых картинок нет, ошибок в скриптах нет.
- Страница читается и работает без интернета, кроме ролика на RUTUBE.
- Шрифт, фотографии и значки лежат внутри репозитория — внешних запросов нет.
